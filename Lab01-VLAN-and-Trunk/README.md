# Lab 01 – VLAN and Trunk

## Overview
This lab demonstrates the configuration of VLANs and IEEE 802.1Q trunk links between Cisco switches.

## Objectives
- Create VLANs
- Configure access ports
- Configure trunk links
- Verify VLAN communication

## Technologies
- Cisco IOS
- Cisco Packet Tracer
- VLAN
- IEEE 802.1Q Trunk

## Verification
- show vlan brief
- show interfaces trunk
- Ping test
